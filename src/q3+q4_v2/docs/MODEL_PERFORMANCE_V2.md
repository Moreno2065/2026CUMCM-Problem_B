# Q3/Q4 性能模型重建：联合停点、试探清除与学习搜索

日期：2026-09-12。模型标识：`q3q4-performance-v2`。

状态：**三条独立控制器已经实现，并在同一合成场景、同一执行器和同一完成判据下直接复核。** 本文不继承旧模型的平均性能结论，也不把研究论文中的最优性或泛化结论移植到本题。

## 1. 本次决定

采用“概率状态 + 联合停点规划 + 试探清除 + 学习引导的在线搜索”。Q3、Q4 共用决策框架，分别处理接收区域与观测似然。机器学习同时学习候选动作先验和剩余任务成本。

解除旧性能策略的六个限制：

1. 不再要求每次清除前把完整可行域压进 20 米圆；合法试探清除可以提前执行。
2. 不再固定 READY > ACTIVE > CERTIFICATE 的日常调度优先级。
3. 不再强制逐源处理后返回发现锚点。
4. 不再用单频道 MEC 收缩/成本作为最终动作目标，也不再用旧 tau 预先删去新策略候选。
5. 不再固定原点扫完 20 频道、每站扫遍未结频道、每源恰好或至多六次测量等性能策略。
6. 不再要求新策略在每一个测试案例中都比旧版快；选择依据是同口径的速度、成功率和运行时间。

保留题面物理规则和真实结果记录。旧几何、覆盖与兜底可以成为候选动作、收尾程序和独立核对工具，不再给每个正常动作附加全相容世界的完成成本上界。

## 2. 题面事实与真正的性能目标

原文见 [B 题](inputs/B题.pdf) 第 1 页问题 3、第 2 页问题 4及第 2–4 页附录；接口见 [附件 1](inputs/附件1.docx)、[附件 2](inputs/附件2.docx)。

| 项目 | 事实 |
|---|---|
| 源域 | 半径 1800 m 的圆域，源静止 |
| 频道 | 20 个频道，每频道至多一个源；初始总数 N 在 10–16 之间 |
| 接收距离 | 每源固定但未知，1000–1500 m |
| Q3/Q4 | Q3 全向；Q4 混合全向和定向，定向为含边界的 180° 扇面 |
| 示向度 | 误差有界于 ±1°；同点同频道固定；接口保留两位小数 |
| near | 距离 ≤5 m 且在信号覆盖内 |
| clear | 距离 ≤20 m 必成功，与信号朝向无关 |
| 虚拟计时 | 移动 5 m/s；检测 5 s；检测换频 1 s；光学失败 3 s，成功合计 5 s |
| 指令 | measure/clear 隐含移动；clear 不改变测向频道；必须串行执行 |
| 运行预算 | enter 返回实际剩余现实时间；最多 1200 s，虚拟上限 360000 s |
| 起终点 | 从原点出发；可以在任意位置 exit，不必回原点 |

原题要求全清，同时报告清除比例和 T/已清除数。它没有给出一个允许任意漏源换速度的单一积分公式。本模型区分：

- **官方结果**：如实报告清除比例、总时间、T/已清除数、运行时间；漏源不能当作达标全清。
- **性能优化立场**：允许概率估计、试探动作、有限概率的策略失败；不要求对所有对抗环境逐一证明最坏完成性。
- **训练代理**：给未完成任务明确有限惩罚，以免“立即 exit”成为数值上最优。惩罚不是主办方计分公式。

对初始源数为 N、结束时清除数为 m 的一局，定义训练损失

\[
L_\Lambda=\frac{T}{N}+\Lambda\mathbf1\{m<N\}.
\]

跨案例优化 \(J_\Lambda=\mathbb E[L_\Lambda]\)，同时报告真实成功率、平均 T/N、分位数和全部失败。\(\Lambda\) 的单位为秒/源，是风险—速度选择参数。初始实验比较 1000、5000、20000；这是搜索网格，不是已校准的最优值。Q3 与 Q4 分开选参数，不能因两题平均更好而牺牲其中一题。

N 仅在离线生成场景、训练标签和事后评估时可用。在线策略只能使用 N 的后验分布，不能读取演练结果文件、源列表或模拟器内部状态。

## 3. 隐状态、观测和概率假设

每频道初始隐变量为

\[
\theta_c=(E_c,g_c,r_c,d_c,u_c,\varepsilon_c(\cdot)),\qquad
N=\sum_{c=1}^{20}E_c\in\{10,\ldots,16\}.
\]

E 表示初始是否存在；g 为位置，r 为接收半径，d 为类型，u 为定向单位向量，\(\varepsilon_c\) 为固定空间误差场。已清除集合 C 是可观察状态，不能把“清除后收不到信号”解释为“初始不存在”。

给定全部历史 H，在线状态取

\[
K=(p,f,C,D,H,b,W,\mathcal R),\qquad b(\theta)=P(\theta\mid H).
\]

p 为当前位置，f 为测向频道，D 为已确认存在集合，包含已清除频道；W 为现实与虚拟剩余时间；\(\mathcal R\) 为尚有用途的覆盖/收尾任务。H 中保留同点观测和失败光学圆，供重建。

题目没有规定位置、半径、方向和误差的概率分布。以下仅为可替换的初始建模假设：

- N 的初始先验在 10–16 上均匀；给定 N 后频道子集均匀。
- 圆域内面积均匀作为一个位置分量，同时训练边缘、聚集、分散分量。
- 接收半径先验为 [1000,1500] 均匀并加入端点压力分量。
- Q4 的定向比例使用层级混合先验，条件于至少一个全向和一个定向源，方向初始均匀；不把本地 random=全定向当作官方分布。
- 空间误差先比较固定独立值、空间相关平滑值和偏向边界的值。每个采样世界保留一致的空间误差，不在同点重复抽新误差。

概率用于决策，保守位置集合用于核对。两者可同时维护，但不要求概率分布的每一个尾部样本都先被排除才允许 clear。概率模型冲突时保留观测、补粒子并恢复到最后可解释状态，不能通过把某频道标为空来清除冲突。

### 3.1 正确的接收与反馈模型

对未清除存在源，令

\[
A_c(x)=\mathbf1\{\|x-g_c\|\le r_c\}
\mathbf1\{d_c=\mathrm{omni}\ \lor\ u_c\cdot(x-g_c)\ge0\}.
\]

measure 返回 no_signal 当 A=0；A=1 且距离 ≤5 返回 near；否则返回 direction，示向度由真实角度加固定误差并按接口量化得到。clear 的成功条件仅是存在、未清除且距离 ≤20。

两位小数示向度的似然应针对整个 0.01° 读数区间积分，并正确处理 0°/360° 环绕。只知道原文总误差界时，几何核对允许保守的量化余量；不能凭有限小数位推断比题面更高的精度。同一位置相同频道的缓存读数不能重复作为独立证据乘入似然。

### 3.2 源数耦合必须进入后验

给定场景类型，设每频道的“初始不存在/存在”历史边际似然分别为 \(\ell_{c0},\ell_{c1}\)。先验使用上述给定 N 的均匀频道子集时：

\[
P(N=n\mid H)\propto
\frac{P_0(N=n)}{\binom{20}{n}}
[z^n]\prod_{c=1}^{20}(\ell_{c0}+z\ell_{c1}).
\]

用 20 阶多项式递推即可计算，避免把 20 个独立存在概率直接相乘而违反总数约束。共享场景或误差超参数时，条件于超参数计算，再按其更新后的后验权重混合；不能用原先验权重平均已经归一化的条件后验。上式不宣称适用于任意相关先验。

Q4 名义先验还要条件于两种类型同时存在。设给定定向比例参数 0<π<1 时，每源类型按 Bernoulli(π) 产生，再条件于混合事件。分别记不存在、全向、定向的历史似然为 ℓ_c0、ℓ_co、ℓ_cd，并令

\[
F(z,w)=\prod_{c=1}^{20}\left[\ell_{c0}+z\{(1-\pi)\ell_{co}+w\pi\ell_{cd}\}\right].
\]

此时须用二维递推：

\[
P(N=n\mid H,\pi)\propto
\frac{P_0(N=n)}{\binom{20}{n}\,[1-(1-\pi)^n-\pi^n]}
\sum_{k=1}^{n-1}[z^nw^k]F(z,w).
\]

分母校正“给定 N 后条件于混合”的先验，k 排除全向和全定向情况。没有观测时，该式应恢复原先 N 的先验。全定向压力集使用单独的场景配置，不硬套名义混合模型；另测将名义策略直接用于该分布偏移时的表现。

确认 direction/near/成功清除后，相应初始不存在似然为零。特别是 |D|=16 时，所有 D 外频道初始存在概率严格为零，可取消其搜索任务；仍须完成 D 中未清除源。只清除 10 个没有同样结论。

### 3.3 Q4 对朝向做条件积分

对每个位置—半径粒子 (g,r)，用圆周区间交集维护可能朝向 U：

- 正信号点 x 增加 \(u\cdot(x-g)\ge0\) 约束。
- 无信号点 x 若距离 ≤r，增加 \(u\cdot(x-g)<0\) 约束；距离 >r 时不增加朝向约束。
- near 还增加距离约束。光学成功/失败只改变位置，不直接约束朝向。

在均匀方向先验下，朝向相容性的边际量与 U 的弧长成正比。连续更新时乘入“新弧长/旧弧长”，不能每次再乘完整弧长而重复计入旧证据。原子方向或边界压力分量须单独处理，不能仅靠弧长丢掉测度为零的边界情况。

这使搜索可以利用 no_signal，又避免旧 E2 的粗方向采样成为硬几何裁剪。全向类型必须一直保留，除非历史已排除。

## 4. 原子动作与联合停点

真实原子动作是 \(a=(\mathrm{measure/clear},x,c)\) 或 exit。联合停点是内部规划对象

\[
o=(x,\sigma_x),
\]

其中 \(\sigma_x\) 是在 x 处根据新反馈选择下一频道和操作的短局部策略；它不是一个同时测多频道的接口。每收到一次响应就更新 K，并允许终止或改变本站计划。

共享移动成本只支付一次，本站各频道检测和清除逐条支付。clear 不换测向频道，因而同站的测量顺序和最后测向频道会影响下一站成本。多个频道在同一位置清除仍需多条 clear。

原子动作的精确虚拟成本为

\[
c_m=\|x-p\|/5+5+\mathbf1\{c\ne f\},\qquad
c_o=\|x-p\|/5+3+2\mathbf1\{\mathrm{success}\}.
\]

动作结果与成本可相关，特别是成功 clear 多 2 秒。所有长回放和训练标签必须使用这一本账，不能用“成功概率×固定 3 秒”近似全部成本。

### 4.1 有依据的候选域缩减

measure 只需考虑 \(B(0,3300)\)，clear 只需考虑 \(B(0,1820)\)。

证明：当 \(\|x\|>1800+1500\) 时，对任何题面合法源均有距离 >1500，measure 必然给出已知的 no_signal；当 \(\|x\|>1800+20\) 时 clear 必失败。这些动作没有新信息，绕行可由直线路径替代。提前换频也不比在下一次真实 measure 换频更省，因此可删除这些严格外部点。边界保留。

此结论使用无障碍直线移动、固定费用和源域约束；它不是以任意采样半径限制最优解。候选域内仍是连续优化问题。

### 4.2 候选生成

每次根决策同时生成以下类型，使用真实几何与概率重评分：

1. 当前位置的有用 measure、试探 clear 和已认证 clear。
2. 每源后验 20 米球概率质量的局部极大点、位置模态、若干粒子加权代表点。
3. 两侧交会测点，步长和偏移可调；原 MEC/固定几何点仅占其中一部分。
4. 可同时改善多个频道的测量停点，以及多个清除区域的交点/短绕行点。
5. 剩余源概率质量较大的探索点、覆盖缺口点、现有骨干点。
6. 连接预计后续任务的路线插入点，经 2-opt、relocate 和连续位置优化改进。

软化距离阈值可以用于提议候选，但最终场景评分使用真实 20 米/5 米/接收角阈值。候选只因重复、明确无信息或费用支配而提前删除；没有“半径下降为零就无价值”的规则。

## 5. 试探清除的成本判据

到达某点 x 后，设 \(p=P(\mathrm{clear\ success}\mid K,x,c)\)，成功/失败后的剩余成本分别为 \(V_+,V_-\)。暂以秒讨论同一来源数固定的比较：

\[
Q_{\mathrm{probe}}=3+2p+pV_++(1-p)V_-.
\]

它应与跳过该动作、继续测量或改去另一任务的成本比较。失败后，剔除该频道在 B(x,20) 内的粒子并记录真实排除圆；不可重新补回已排除的位置。

一个明确的局部简化例：成功后当前子任务成本为 0，失败后仍需 V0 秒，绕路额外成本为 d，则

\[
Q_{\mathrm{probe}}=d+3+2p+(1-p)V_0,
\quad Q_{\mathrm{probe}}<V_0
\iff p>\frac{d+3}{V_0-2}\quad(V_0>2).
\]

当 V0=60 秒时，原地试探的门槛约 5.17%；额外绕路 200 m 即 d=40 秒时，门槛约 74.14%。因此不能全局固定“成功率超过 95% 才 clear”，也不能不计绕路地到处试探。

若仅作算例，位置在半径 30 米圆盘内面积均匀，中心处清除成功率是 4/9。取 d=0、V0=60，试探预计 37.22 秒，比跳过的 60 秒少 22.78 秒。这验证决策机制的可能收益，**不是 Q3/Q4 整局仿真成绩，也不是对真实后验形状的假设**。

## 6. 总成本 Bellman 定义

令 \(V_\Lambda(K)\) 表示从 K 出发的期望剩余归一化成本加最终失败惩罚。状态还含时间预算；在有限窗口内令折扣因子为 1，不以折扣人为偏爱拖延未来成本。

\[
V_\Lambda(K)=\min\left\{
\Lambda P_b(N>|C|),
\inf_{a\ne\mathrm{exit}}\mathbb E_{\theta,Y\mid K,a}
\left[\frac{c(K,a,\theta,Y)}{N(\theta)}+V_\Lambda(K')\right]
\right\}.
\]

第一项是主动退出的训练代价；预算截止同样施加未完成惩罚。已发生的成本无需再次加入。在线 n 未知，使用场景中的 N 对增量逐个归一化再平均，不能把平均总时间除以平均源数。

贝叶斯期望依赖建模假设，且上述连续高维问题不作精确求解承诺。它的作用是把所有候选放在同一成本目标下，使“移动、信息、清除、早停、尾部收尾”不再使用互相冲突的代理分数。

实际终止记录分两类：

- `CERTIFIED_COMPLETE`：16 个不同频道已清除；或所有频道已清除/有有效空间或基数证书。
- `MODEL_STOP`：基于后验与成本主动停止，没有全清证明。若事后发现漏源，按失败计入成绩和训练，绝不能改标为 certified。

`MODEL_STOP` 作为独立开关比较；先测禁用它的性能，明确其额外收益与漏源率。任何模式都不把仍有确定存在但未清除的源隐去。实验接受经验风险，不声称对所有未知环境零风险。

## 7. 求解：滚动联合搜索，所有反馈之后重新决策

不直接求整个连续 POMDP 的精确解。在线采用有限场景、有限候选的信念树搜索，先用短程场景束搜索做可复现基线，再比较 POMCPOW 风格的加权粒子树搜索。

每一步执行：

1. 根据实际反馈更新 b、位置、频道和剩余预算，更新尚可复用的树。
2. 产生第 4.2 节的候选，保留原地、跨频道、清除、探索和收尾等不同类别。
3. 从联合后验抽场景。比较根动作时尽量使用同一组场景，降低差值估计的方差。
4. 搜索“停点—局部检测顺序—后续路线”。动作和观测分支逐步扩展，连续观测分支用条件加权粒子更新。
5. 叶节点用便宜的完整策略 rollout 或学习价值补足尾部。选取估计剩余损失最低的根动作，只执行它的第一条实际指令。

树必须满足**非预知性**：同一可观察历史上的动作相同。不能分别查看每个隐藏世界的真源坐标，选出各自最优路线，再把平均值当作在线可实现价值。不同场景只有在模拟反馈不同后才允许分支。

直接给每个新方位角创建单粒子观测节点，会把不确定状态错误地变成近似已知状态。采用 POMCPOW 类更新时，需保留观测似然权重与有效样本量；实际接口虽然量化到 0.01°，分支仍然很多。使用观测聚类时，在分支内按原始似然重新加权，不能把一个角度箱中的全部世界视为等可能。

计算参数从可剖析的小网格起步，例如根候选 32/64/128、根粒子 128/256/512、短程深度 2/4/8；它们是待测预算，不是性能结论。对低概率高成本尾部保留覆盖候选。动作候选和粒子数须随本机实际速度调整，不把理论上更深的搜索等同于更强表现。

折扣因子取 1，成本与第 6 节一致。深度截止时不能把后续成本记为零，否则搜索会偏好把清除和难源拖到树外。根动作差异远大于采样误差时可以提前停止搜索；接近时增加场景或扩展有争议分支。该置信比较仅是分配算力的启发式，不是最优性证书。

现实预算 W 是状态的一部分。每条反馈记录计算耗时，按剩余任务量分配下一步搜索配额，并保留退出及必要接口调用的时间。先测本机吞吐，再定每步时间；不得用无界搜索耗尽 1200 秒。

## 8. 学习策略：学后续成本和联合动作，不复刻旧规则

研究路线参考 BetaZero 的信念搜索与策略/价值学习，以及 GammaZero 的图式信念表示。两者提供结构上的依据，没有在本题上的现成性能保证。

### 8.1 状态表示与预测量

使用机器人、20 个频道、候选停点/任务构成的图。图中包含：

- 机器人位置、上次测向频道、剩余预算、已经执行的动作计数。
- 每频道存在概率、已发现/已清除状态、位置多峰摘要、半径分布、Q4 全向概率及方向弧摘要。
- 候选点相对坐标、移动时间、可检测/可清除概率、与多个频道的关系。
- N 的后验、当前路线和剩余覆盖任务摘要。

多峰后验不能仅用均值和协方差压成一个假源；保留若干加权峰或粒子集合编码。频道编号除了测向换频关系外不赋予固定优先级。旋转/反射增强必须同时变换方向、方位角、误差场和轨迹。

网络输出动作先验 P(a|K) 和剩余归一化损失 V(K)；可增加清除成功率与未完成概率辅助头用于校准。先比较轻量 MLP/树模型与图网络的收益和耗时，网络大并不自动胜出。在线输入严禁包含真实 N、源坐标、真实类型、尚未观测的误差或未来反馈。

### 8.2 数据与训练流程

1. **先有快模拟与成本搜索教师。** 教师仅使用当前可见历史，采用联合候选和完整 rollout；离线模拟器真值只负责产生反馈与结算。
2. **收集动作成本差。** 同一信念、相同场景采样下，执行不同根动作后用同一合法后续策略完成，记录总成本、失败和计算量。标签是后续损失，不是旧 gain/cost 分数。
3. **迭代收集新策略访问状态。** 模仿学习参考 DAgger/AggreVaTe 的分布修正与成本敏感思想，逐步加入新策略遇到的困难状态，避免只会旧策略走过的轨迹。
4. **蒸馏搜索。** 以搜索估计成本形成动作目标分布，以实际完整 rollout 的剩余成本/N 加终止惩罚训练价值。样本数、方差、失败样本同时保留，不把一次偶然高分当成稳定优越标签。
5. **可选策略优化。** 搜索蒸馏收敛后，才比较直接策略梯度或偏好训练是否提高独立验证表现。训练回报与第 2 节一致，避免仅奖励 MEC 缩小而改变目标。

价值损失可用 Huber，策略损失用交叉熵；辅助概率用适当评分规则并检查可靠性曲线。损失权重属于验证集参数。既有六特征学习器可作对照，不把复制的历史模型称作本轮重新训练结果。

模型选择以独立验证中的全清速度、失败率和实际耗时为准。最终模型及归一化参数在留出集运行前锁定。留出集只作一次最终评价；观察结果后再改参数，该集就转为开发集。

## 9. 两题分别发挥什么优势

**Q3：重点是减少绕路和多余复测。** 规划一个停点时，检查它对全部未结频道的价值；沿多源访问路线获得有用交叉角。清除候选可来自高概率 20 米覆盖圆，不等待整个误差可行域收缩完成。对已经发现 16 个不同频道的局面，立即删除其他频道探索需求，但已发现源仍须逐个清除。

**Q4：重点是联合推断位置与可见侧。** `no_signal` 可能由空频道、距离或朝向产生；搜索应比较穿过另一侧、沿行进路线再听一次以及直接试探清除的后续成本。对“位置已较集中、接收侧尚不确定”的源，清除不依赖信号朝向，可能比反复找接收侧更便宜。这个收益取决于实际后验，不能固定为“定向源总是盲清”。

两题都按实际反馈中断局部动作序列。例如某次清除成功后立刻删除该源后续检测；某频道首次有信号后立刻更新总数后验；某个试探失败后删除对应 20 米区域并重新规划。局部动作顺序的收益也要在串行接口上兑现。

## 10. 判断目标差距：有效下界与可执行结果分开

已知全部真位置的离线问题，可以跳过测向，从原点出发进入每个清除圆 B(g_i,20)，最后任意退出。其最优虚拟成本为

\[
T^*_{\rm full}=5N+L^*_{\rm open\;TSPN}/5.
\]

这只是具有额外信息的松弛。其最优值不超过原在线任务最优值。

一个便宜且有效的下界：建立原点和 N 个清除圆的完全图，边权为集合间最短距离：

\[
w_{0i}=\max(0,\|g_i\|-20),\qquad
w_{ij}=\max(0,\|g_i-g_j\|-40).
\]

记最小生成树权重为 M，则

\[
5N+M/5\ \leq\ T^*_{\rm full}\ \leq\ T^*_{\rm online}.
\]

理由：任意可行访问路径中按首次访问各圆连接成树，每段路长至少为相应集合间距离；取 MST 再放松。边权不必满足度量三角不等式，这个论证仍成立。下界只用于诊断，不给在线策略读取真值。

另算访问源中心的最短开放路线，在 N≤16 时可用子集动态规划，或使用路线启发式取得可行解。它提供全信息问题的**上界**，不能用来证明在线目标不可达。一般关系是 LB≤全信息最优≤全信息可行解，同时全信息最优≤在线最优；全信息可行解和在线最优之间没有固定大小关系。

基线账本、oracle 路线、预测节省量、新策略实测四类结果分别存储。禁止把“删除旧 cert 行”“模型预测更便宜”“使用真值规划”标成新策略官方成绩。

## 11. 实验设计与是否采用的依据

### 11.1 对照组

| 组 | 内容 | 回答的问题 |
|---|---|---|
| A | 历史可运行策略，参数锁定 | 当前真实参照 |
| B | 新成本动作库 + 试探清除 + 联合停点，便宜 rollout | 不训练是否已经获益 |
| C | B + 信念场景搜索，仍无学习模型 | 搜索本身是否值得计算开销 |
| D | 学习模型直接选动作，无树搜索 | 学习能否摊薄在线计算 |
| E | 学习引导的信念搜索 | 最终组合是否优于 B/C/D |
| F | 最优前一组 + MODEL_STOP | 主动退出带来多少速度和失败变化 |

同时单独消融试探清除、联合停点、基数推断、Q4 方向弧、图网络。候选池大小、场景数和现实计算预算应尽量匹配；不能给学习法更多算力再把全部收益归给学习。经典路线改进也保留作竞争基线。

### 11.2 场景与划分

- N 覆盖 10–16；先以 10、13、16 做小规模覆盖，再扩展全部基数。
- Q3 包含面积均匀、边缘、成簇、分散场景和不同接收半径。
- Q4 名义集分别覆盖约 25%、50%、75% 定向，生成时确保同时包含两种类型；全定向单列压力集，不能混入名义集后统称官方分布。
- 误差测试覆盖同点固定、空间相关、边界偏置；概率结论都注明生成器。
- 地图、半径、朝向、误差场整体标识用于 train/development/test 划分；同图不同 seed 或几何对称变换不得跨集合。缓存和学习标签随划分绑定。
- 历史说明中已有重复地图导致训练/留出泄漏的记录。新的独立集合需重新查重，不能沿用旧报表中的“holdout”称呼推断无泄漏。

本地匹配实验在同一场景与同一固定误差场上运行各策略；接口预算另行控制。只有现存一局官方 Q3 和六局本地 Q4，不能把它们当成同分布样本合并算显著性。

### 11.3 必须输出的指标

每局保存初始 N、清除 m、T、T/m（m=0 为不可用）、T/N、全清标记、失败原因、移动/检测/换频/清除分账、现实耗时与终止类型。报告全体失败率以及全清局的 T/N 均值、中位数、P90；另外列全体局的训练损失，不能只显示成功局而隐藏失败。

跨局主均值用每局 T/N 的平均，不用总 T/总 N 偷换。朋友目标命中率分别定义为“全清且 Q3 T/N≤176.25”“全清且 Q4 T/N≤290”，其中 Q3 的 16 源子集另外报告总时间是否≤2820。不同 N 归一化后仍可能有密度与共享路线差异，因此还须按 N 分层。

给出配对差值的区间估计，失败率给二项区间。即使 1000 个独立同分布案例全部成功，一侧 95% 精确失败率上界仍约为 0.299%；这不是全环境完成性证明。分布偏移另行用压力集报告。

模型选择使用验证集上的速度—失败率曲线。有限惩罚 Λ 可调，但官方全清目标保留；一个靠明显漏源获得低 T/m 的策略不能写成“达到朋友全清成绩”。

## 15. 当前生产复核覆盖（v2，2026-09-12）

为避免历史段落与当前入口混淆，当前推荐配置以
`tuning_runs/final_recommended_v2_summary.json` 为准。它在 5 个共同 seed、
Q3 random/Q4 mixed、10/16 源上完成 20 局，20/20 局 `complete=true` 且
`verifier_all_ok=true`。Q3/16 平均 269.228 s/源、P90 280.502；Q4/16 平均
383.173 s/源、P90 445.614；Q3/10 和 Q4/10 分别为 437.356、801.032。

主线结构是：Q3 保留稳定的 observation-only 自适应扫描和有限覆盖兜底；Q4
把补覆盖、ACTIVE 补测、保证清除和有限试探放进 horizon=3 的滚动候选池，
并根据中心停点的方向观测比例（阈值 0.1）选择证书访问顺序，同时保留
sparse25/基数证书完成条件。直接把 140 m 或 MEC 半径转成清除动作
会产生失败尾部；13 点环和硬性 Q3 直达圆心也没有在共同种子上稳定胜出，
所以都只保留实验开关。开放路径 2-opt 只重排兜底序列的安全后缀，不牺牲已
尝试前缀和最终覆盖保证。

朋友给出的 Q3 176.25、Q4 290 s/源仍是外部参考，不是本地可验证的约束。
当前结果已经支持“重建后的路线全清稳定，并且 Q4 滚动规划降低平均成本”，
但不能推出达到目标或对朋友未知评测分布全局最快。

Q4 证书顺序的独立 20 种子留出复核为 468.039→464.710 s/源（16 源），
P90 与最大值也下降。候选顺序保留完整 sparse25 集合，只改变开放路径次序，
所以它可以作为生产默认；Q4/10 的均值几乎不变，入口仍然不读取源数标签。
