# 实施与验证顺序

本文件记录从资料归档到可运行策略的实施路径。三条控制器、统一执行器和同场性能复核已经完成；大规模学习训练与官方接口实测仍属于后续工作。

所有新增源码、配置、训练记录、模型权重和实验结果继续写入本目录。`baseline/` 为只作对照的历史快照；三条新路线分别放在 `geometry_joint/`、`probabilistic_search/`、`learned_search/`，各自的运行输出与统一配对摘要放在对应 `runs/`、`comparison_runs/`，避免新旧身份混淆。

## 阶段 1：统一真值模拟、可见状态和成本账本

复用历史接口协议及已核对的执行细节，实现无 HTTP、可关闭逐步日志的快模拟器。分别暴露仅接受动作的策略接口、反馈接口和离线评估器；策略不能引用真源列表。将历史几何程序作为可选组件，不带入旧调度顺序。

必须覆盖的实际语义：同点固定误差、角度环绕、半圆边界、near 受可见性约束、clear 不受朝向限制、重复 clear 失败、clear 不换频、源数 10–16、清除后无信号、起点原点且不必返回。

输出 `code/simulator`、`code/protocol`、精确分账回放、吞吐报告。用已有动作序列复核成本，与旧模拟器做差异检查；若两者冲突，回查题面，不能默认旧实现正确。独立检查实际运行预算。

完成条件：关键边界案例和真实账本对齐；生成、执行和结算分离；相同 seed/误差场可复现。只跑旧测试不算完成新模拟验证。

## 阶段 2：实现概率状态与成本动作库

建立 `code/belief`：存在/基数后验、位置—半径粒子、Q4 条件朝向区间、固定误差记录。建立 `code/candidates`：原地多频道动作、高概率清除圆、双侧测向点、跨源停点、覆盖收尾点和路线插入。

先用便宜完整 rollout 比较动作成本，生成 B 组。保留历史策略作为 rollout 选项及失败回退；正常候选排序不走旧 READY/ACTIVE/CERT 队列。

验证：小型离散世界中与穷举后验相对照；D=16 后外部频道概率为零；重复观测不增加独立证据；失败 clear 更新位置；多峰后验不被错误合并。动作数值例必须通过真实执行器重演。

完成条件：B 可单独运行完整 Q3/Q4，保存全部失败和成本，并在固定小型开发集与 A 配对比较。尚无提升时先定位候选和预测误差，不能用训练掩盖账本问题。

## 阶段 3：联合场景搜索与现实预算

先实现可打印策略分支的短程束搜索，再比较加权粒子树搜索。每次仅执行第一条实际指令，反馈后更新树。叶值先用完整 rollout，避免截断尾部成本。

验证：相同历史不能因隐藏真值不同而选择不同动作；改变动作能够改变后续观测和信念；原地跨频道动作节省移动确实计入；搜索预算耗尽仍可及时返回动作。记录每根动作的估计均值、样本量、方差和实际后续损失。

输出 C 组、节点/场景吞吐、计算时间分布和对 A/B 的配对表。只在已测预算内扩展树深度。

## 阶段 4：成本标签和学习引导

按独立地图划分生成教师数据，先检查地图及几何对称副本的哈希去重。每个标签记录可见状态版本、场景采样 seed、教师版本、候选成本、失败、剩余预算和训练归属。状态中不得存入仅评估器可见的字段。

先训练轻量策略/价值模型，形成 D/E，再测试图模型。使用新策略轨迹做数据聚合，保留失败和困难尾部，记录标签生成速度与模型推理耗时。性能有稳定收益后再考虑昂贵的策略优化。

完成条件：学习方案在相同现实预算下优于不学习的最佳方案，或以可接受性能代价显著降低计算时间；否则交付表现最好的 B/C，不为采用机器学习而退步。所有模型标注训练集、参数、代码和配置哈希。

## 阶段 5：独立评价与正式候选

验证集上分别给 Q3/Q4 选择 Λ、搜索配额、粒子数、候选参数及 MODEL_STOP 开关，输出速度—失败率曲线。锁定后在独立留出集运行一次。

报告每组样本量、源数分层、Q4 类型比例、误差模型、全清率、全清 T/N 分布、全体损失、配对区间、现实预算超限次数及朋友目标命中率。全定向压力集单列。统计方法不把分布外保证写进结论。

正式运行消耗有限次数，不在模型设计或普通回归时自动调用。先交付能够离线检查的候选包和完整证据，再按届时已有的用户授权使用正式接口。

## 阶段退出原则

每阶段都留下可运行、可比较版本。实测输给前一阶段时保留前一阶段作为候选，不把理论复杂度当作强制升级理由。新发现题面实现错误先修复再重跑受影响比较；仅改变文档或参数说明不重复无关大实验。

成绩认定只使用实际执行轨迹。朋友目标尚未达到时，报告真实差距与分账，不使用预测或下界替代成绩。
