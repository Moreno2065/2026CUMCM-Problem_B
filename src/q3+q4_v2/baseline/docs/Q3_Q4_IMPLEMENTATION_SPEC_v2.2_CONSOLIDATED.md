## 1. 固定条件、状态和目标

目标域 Ω=B(0,1800)，20 个频道，每频道至多一个静态源，总数 10–16。有效接收半径在 [1000,1500] m，Q3 全向，Q4 可定向，定向覆盖为包含边界的 180° 半平面。示向误差界为 ±1°，同点同频道误差固定；near 阈值 5 m，清除阈值 20 m，清除不受源朝向影响。

频道知识状态为 UNKNOWN / ACTIVE / READY / CLEARED / CERTIFIED_ABSENT；FALLBACK_CLEAR 是 ACTIVE 的执行子模式。全局异常状态单独记录，不混入不存在证书。

每频道保留原始反馈、保守位置外包 P、已证空域、正负测点、MEC、保证清除区域 Z、首次发现锚点与方向、骨干未完成项、局部测量余额和已执行清除点。全局保留位置、测向频道、已确认存在集合 D（包含已清除频道）、成本分项及剩余保证性任务。

先保证真实源全清与合法结束，再在相同案例上比较效率。全清案例主指标为 T_j/n_j，跨案例采用这些比值的算术平均；n_j 仅用于事后评估。未全清时报告清除率和 T_j/n_cleared，零清除记未定义；失败不能因耗时较短而进入成功策略排名。

## 2. 官方动作与反馈契约

### 2.1 四接口及必要字段

本节已直接对照附件 1、附件 2。不存在独立移动或换频指令；同站批量扫描也是多个串行单频道动作。

| HTTP 动作 | 请求字段 | 主要成功响应字段 |
|---|---|---|
| POST /enter | arena_id、robot_id、request_id | accepted、real_timestamp_ms、virtual_time_s、max_virtual_duration_s、max_real_duration_s、remaining_real_duration_s |
| POST /measure | 公共三字段 + position={x,y} + channel | accepted、real_timestamp_ms、virtual_time_s、measure_result；direction 时另有 svd_deg |
| POST /clear | 公共三字段 + position={x,y} + channel | accepted、real_timestamp_ms、virtual_time_s、clear_result |
| POST /exit | arena_id、robot_id、request_id | accepted、real_timestamp_ms、virtual_time_s、exit_reason |

arena_id 为 default，robot_id 从用户配置读取，request_id 为本次会话的幂等键。坐标单位 m，必须有限且各坐标绝对值不超过 2000000；channel 为 1–20。JSON 字段拼写及完整约束直接遵循附件 2，不发送未声明字段。

measure_result 为 direction / near / no_signal，示向字段是 svd_deg。clear_result 为 success / no_target_in_range。旧的 result、bearing、remaining_time 及独立移动请求示例均不得作为正式 schema。

### 2.2 生命周期、计时与异常

成功 enter 后初始位置为 (0,0)，测向频道为 1。移动由 measure 或 clear 的 position 隐式触发；只有合法 measure 可更新测向频道。clear 的 channel 仅指定清除目标。

统一成本为

$$T=L/5+5N_m+N_s+3N_o+2N_h.$$

N_o 含全部合法光学尝试，N_h 为成功清除数；每次失败为 3 s，每次成功为 5 s，另计移动。enter、exit 不推进虚拟时钟。

一次只发送一个新动作。网络不确定时重试同一逻辑动作，复用原 request_id、原请求体；完整响应仅更新一次状态与账本。不得用新幂等键盲目重发可能已生效的动作。

同时检查 HTTP 状态与 accepted。accepted=false、拒绝、通信异常均不产生物理约束；拒绝响应的 virtual_time_s=0 不是当前虚拟时刻。动作是否执行尚不确定时保留待核实状态，不凭猜测推进位置或清单。

现实预算使用 enter 返回的 remaining_real_duration_s，不能固定假设有 1200 s。虚拟预算为 360000 s。测试结束后接口关闭，不能事后调用 exit 查询结束原因。现实吞吐、几何运算与日志成本须单独验收。

### 2.3 物理反馈更新

| 合法反馈 | 约束与状态更新 |
|---|---|
| direction | 确认存在；加入 ±1° 楔形、距离 >5 且 ≤1500、保存正观测点 |
| near | 确认存在且距离 ≤5；当前位置保证清除 |
| Q3 no_signal | 至少排除测点的闭 1000 m 圆盘；累积不存在证据 |
| Q4 no_signal | 主线记录证书见证，不直接排除 1000 m 圆盘；E2 才使用联合状态收缩 |
| no_target_in_range | 未清除存在分支排除闭 20 m 圆盘；保留失败点及正常成本 |
| success | 该频道计一次清除成功，删除后续任务，仍属于 D |

已确认存在频道出现空可行域、保证清除失败、完整兜底覆盖耗尽仍失败，均触发矛盾记录。保存最后可靠的外包、原始反馈和覆盖清单以便重建；不能移入 CERTIFIED_ABSENT，也不能报告全清。

## 3. 几何、READY 与在线效用

### 3.1 保证清除位置

对已确认存在、非空且包含真源的位置集合 P，定义

$$\operatorname{MEC}(P)=(z,R),\qquad Z=\bigcap_{g\in P}B(g,20).$$

Z 非空当且仅当 R≤20；READY 必须附可核验的清除位置。主线选取 Z 内距当前位置最近的点；数值求解不能证明所选点属于 Z 时，退回经认证可行的 MEC 圆心。near 基线原地清除。

已有下一任务点 q 时，允许比较 Z 内最小化 ||p−z||+||z−q||−||p−q|| 的插入点，受 §7 的剩余预算约束。最近清除点和最小插入点是不同优化问题，不能混称。

直径≤40 仅为必要条件。仅当 P 确实由保守凸多边形表示时，才可用全部顶点代替整个集合验证清除圆；弧边、非凸集合或位置样本不能直接套用顶点结论。

### 3.2 主动观测准则

对相容反馈集合 Y(K,a)，使用

$$\Delta R(a)=R(P)-\sup_{y\in Y(K,a)}R(P^a(y)),\qquad U_R(a)=\frac{\Delta R(a)}{\|p-S\|/5+5+\mathbf1_{c\ne c_{current}}}.$$

必须包括全部相容 direction、near、no_signal 分支。离散角度扫描如无保守误差界，只是收益估计，不能称为已求出连续最坏值，也不能用来作证空或保证清除。

ΔR/成本是局部代理。更完整的候选评价可采用“本动作成本 + 最坏后验剩余清除成本”，估计项须标为启发式。ΔD/成本仅留作对照；发现与证书任务不能因 ΔR=0 被永久丢弃。

Q3 专属保证链优先遵循 §4；上述 NBV 不得任意替换其测点后继续引用六次界。

## 4. Q3 主线：一次方向后的保证性 MEC 链

首次 direction 位于半径 1500 m、半角 ε=1° 的扇形。令测点为 S、示向单位向量为 v，a=1500/(2cos ε)，则扇形包含于 B(S+av,a)。因此当前集合的 MEC 半径满足 R_0≤750.114246 m<1000。

主线循环：

1. near 或已有经认证的 Z：保证清除。
2. 否则到当前保守可行域的 MEC 圆心检测同一频道。
3. 全向接收保证给出 direction 或 near。direction 更新后满足 R_(t+1)≤R_t/(2cos ε)，继续循环。

首次方向之后，第五次后续方向的最坏半径约 23.459 m，第六次约 11.731 m。因此至多六次后续方向确认；不含首次发现和最终 clear。完整推导见模型正文 §5。

理论链中 no_signal 是矛盾工况，不是正常降低置信度或证明不存在。保守外包的数值误差必须纳入认证半径；若近似方法不能保持该递推，不得以“最多六次”强行截断。

同站对其它频道测量不改变本频道信息，也不增加其方向确认次数，但有时间成本。额外移动、非 MEC 测点和跨目标调度只能在剩余完成预算成立时采用。

Q3 骨干为原点和六个半径 900√3 m 的等角外围点。连续覆盖半径≤900 m；七点全部 no_signal 可证频道不存在。已存在频道由局部链清除。

## 5. Q4 主线：31 点发现与有限光学兜底

### 5.1 已证明的有限检测构造

取三角格点 v(i,j)=950(i+j/2,√3j/2)，保留

$$361(i^2+ij+j^2)\le3025.$$

点集共 31 点，整数平方范数为 0、1、3、4、7，重数分别为 1、6、6、6、12；完整索引见模型正文 §7.1。实际最远半径为 950√7≈2513.464 m；2750 m 是截断半径，没有“两个点位于 2750 m 环上”。

任意目标 g∈Ω 所在闭等边三角形的三个顶点距 g 均≤950<1000，距原点均≤2750，全部在有限集内。g 是三顶点的凸组合，任何以 g 为边界的闭半平面至少包含一个顶点。格点重合用六邻点，格边和圆域边界按闭集处理。

因此每个真实源必在骨干上被发现；未解决频道在 31 点全部 no_signal 可证不存在。该证明只负责发现/排除，不单独证明清除。

数学证明和 [独立核验](D:/CUMCM2026/review/20260911/MODEL_LOGIC_CHECKS.md) 支持将 31 点列入模型主线。程序实际生成的坐标、访问记录、容差及频道证据须由运行时 verifier 另验；不能只检查 len(points)==31。更稀疏构造仍属 E1 候选，须独立认证后才能替换。

### 5.2 ACTIVE 有限预算

基线每源最多 m=6 次额外测量，候选限定 B(0,5000)。全部合法 ACTIVE 测量，包括机会观测，计入该频道同一个不可重置余额。进展停滞、候选耗尽或剩余时间不足可提前进入兜底；不能因一点收缩、换目标或重新规划补回次数。

m=6 是冻结的有限策略取值，不是最优次数定理。旧的 24 次主频道预算、另加无限机会观测、按 10%/三次停滞重新补预算等，均不能继承本版时间界。

### 5.3 100 点完成保障

保存首次骨干 direction 的锚点 A 与示向基 v、v_perp。令 h=1500sin1°，首次方向可行域包含于局部矩形 0≤x≤1500、|y|≤h。固定清除点为

$$z_{k,\pm}=A+(15+30k)v\pm(h/2)v_{perp},\qquad k=0,\ldots,49.$$

50 列、2 行，每格最远覆盖距离 √(15²+(h/2)²)≈19.908036 m<20。最多 100 次光学尝试必有成功，不依赖定向接收。两行蛇形内部路径为 2940+h<3000 m，光学与激光成本≤99×3+5=302 s。

每次合法失败消耗一个未执行项并排除对应清除圆，固定清单不能重置。仅在证明剩余可行域仍被未执行清除圆覆盖时，才能删点、缩小覆盖或改变构造。面积除单元面积和离散位置抽查不构成连续覆盖证明。

兜底优先连续完成当前频道。序列耗尽仍未成功必须保持“已存在但未解决”并报告矛盾；有限停机不能冒充有限步全清。

## 6. Q4 信息增强的支线边界

主线保留 signal/no_signal/clear 历史，使用确定性空间证书。E2 默认关闭；打开后维护或保守近似潜在状态 (g,r,kind,u)，包括全向/定向类型。

对存在分支定义 V(S)=[||S−g||≤r] 且 [kind=omni 或 u·(S−g)≥0]。no_signal 排除 V(S) 成立的组合，再与历史联合并投影到位置；不能把当前猜测的半径或朝向当真值硬裁剪 P。

若只用于候选排序，不宣称已经收缩位置外包；若实际裁剪位置，则必须验证真源包含性与保守投影。无可靠误差界时，E2 不参与 READY 或 CERTIFIED_ABSENT 判定。

固定源接收区是凸集，其全部正观测点的凸包是保证接收区。这一性质可支持候选筛选，但单点或细长凸包未必能定位；Q4 MEC 圆心也未必在接收区内。完成性始终由 §5 兜底承担。

## 7. 冷启动、停点扫描与三模式调度

### 7.1 冷启动与有限任务

enter 后在原点按频道 1–20 完成一次串行冷启动扫描，建立初始知识。near 可原地清除；direction 保存为待处理局部任务，避免把“没有 ACTIVE”误当完成。原点扫描属于骨干清单，不重复添加。

骨干任务为 (point_id,channel)：Q3≤7×20，Q4≤31×20。合法扫描完成后消耗该项；已清除/已证明不存在的频道可删剩余项。基线完成一个已发现源的局部任务后回发现锚点恢复扫描；回程由下一个真实动作的位置体现，尾部无待办时不空走。

### 7.2 正常三模式与公平性

正常候选按 CLEAR（READY）> LOCALIZATION（ACTIVE）> CERTIFICATE 排序；FALLBACK_CLEAR 是必须完成的有限局部任务，异常处理独立。该优先级服从有限预算与剩余基线约束，不允许 ACTIVE 永远阻塞未知频道。

无 READY/ACTIVE 时直接选择未完成骨干点继续发现；CERTIFICATE 同时负责未发现源的搜索与末期证空，不能写成只有主发现结束后才有意义。

达到任务停点后，对 UNKNOWN 频道做批量扫描；已处理的同点同频道结果可复用，CLEARED/CERTIFIED_ABSENT 跳过。ACTIVE 机会式观测须通过收益/成本阈值 τ，且消耗局部余额；移动途中没有免费连续观测，一次 HTTP measure 只检测一个频道。

清除点插入、状态感知频道顺序、残余证书 ΔC/成本均为可比较策略。ΔC 是有明确几何定义的新增已证面积或保守下界；采样覆盖率只作估计，不能凭“100% 样本覆盖”判不存在。

### 7.3 优化动作的预算条件

每个额外动作必须同时满足：有限任务账本不重置，所有相容后验下仍有已认证的剩余完成路线，动作成本加保守剩余成本不超过剩余虚拟预算。无法认证时执行基线。

骨干外的 UNKNOWN piggyback scan 会增加动作，且首次发现锚点可能不在 B(0,2750)；必须按实际锚点重算光学路线和余量。它不能直接引用骨干基线的 273808 s 上界。其成本和发现记录写入 decision trace；证据不足时只在骨干停点批扫 UNKNOWN。

## 8. 结束条件和时间证明适用范围

D 包含已清除频道。当 |D|=16，可由总数上界排除其它频道，但仍须完成这 16 个目标。清除 10 个不是停止条件。

成功结束仅允许：已清除 16 个不同频道；或全部 20 个频道均 CLEARED/具有有效空间或基数证书的 CERTIFIED_ABSENT。E2 的额外证空依据需单独认证。通信失败、超时和知识矛盾可以结束运行，但必须记未完成。

骨干基线及 §4–5 的局部策略满足：

| 项目 | 保守上界 |
|---|---:|
| 检测 | 31×20+16×6=716 |
| 光学尝试 | 16×100=1600 |
| 成功清除 | 16 |
| 含 enter/exit 的合法指令 | 2318 |
| 骨干路径 | 30×5500=165000 m |
| 每目标局部路径 | 6×10000+7800+3000+1600=72400 m |
| 总虚拟时间 | 273808 s≈76.058 h<100 h |

提前 READY 的清除点模长≤1820 m，其清除及回锚点路径也包含在该界内。Q3 可收紧为 236 次检测与 16 次清除。证明详见模型正文 §11。

这些是指定基线的充分性上界，不是平均成绩。换 m、扩大候选域、增加批扫或改调度后须重验；现实 20 分钟预算须另验，不能由指令有限直接推出。

## 9. 数值认证与独立 verifier

容差按单位和作用分开：角度 rad/deg、坐标/距离 m、包含关系/面积 m²、时间 s、坐标去重阈值。题设常量不能用数值容差随意放宽；具体计算容差由几何误差界及边界测试确定并写入配置。

保证判断使用外包/上界：清除以 sup 距离的上界≤20 为准，接收以认证距离界为准；不能用 R_est≤20+tol 扩大物理清除范围。内接圆多边形可能丢真源，位置样本可能遗漏极端点，均不能直接作为保证依据。

31 点静态 verifier 检查完整整数索引、几何坐标、边界和格点退化；逐频道 verifier 重放全部 accepted 反馈并确认对应见证点。Q3 核查覆盖及 MEC 链前提；光学兜底核查连续剩余域覆盖与已执行项。安全判定的 verifier 不复用生产模块的同一判断函数作为唯一依据。

分开记录：连续数学证明、独立算术/数值反例检查、实际几何与状态实现检查、synthetic 真值检查、官方外部行为检查。当前数学核验不是后三者通过的凭据。

## 10. Mainline 与 Experimental Branch

主线包括集合状态、Q3 MEC 链、Q3 七点/Q4 31 点证书、MEC/清除区域准则、有限 fallback、冷启动、状态感知停点扫描、带预算的机会机制、接口映射和证据契约。机会机制在尚无已选 τ 或安全预算时关闭，保留保证性基线。

| 支线 | 默认状态与目的 |
|---|---|
| E1 更稀疏 Q4 证书 | 关闭；31 点之后的减点或路线新构造须重新证明 |
| E2 no_signal 联合状态 | 关闭；见 §6 |
| E3 多步 lookahead / 路线插入增强 | 关闭；减少时间，保留剩余基线 |
| E4 证书残差稀疏化 | 关闭；删点必须有覆盖依据 |

支线须独立配置、独立结果目录，不能悄悄改变主线。晋级 supporting result 要求相同 cases/误差场/预算/成功定义，独立 verifier 通过、不降低清除率，并稳定改善时间、距离、稳健性或证据强度中的至少一项；只能声称实际改善的指标。

破坏完成性、依赖额外概率假设、仅最好 seed 获益、matched-budget 无稳定收益、现实耗时明显增加而无补偿、证明无法闭合或需修改主线前提时，停止或降级。正式主线晋级须在最终配置冻结前完成，不能看正式结果后选算法。

## 11. 调参、数据隔离与四组消融

### 11.1 参数与冻结

A 类为题设常量和已选定理构造参数，不作经验调参；B 类为下一测点、清除点和频道顺序等在线决策变量；C 类当前仅为机会观测阈值 τ，不新增无依据自由权重。m=6、950 m、50×2 属本版策略/构造参数，修改需重验理论预算。

τ 使用收益/成本定义后再设小规模候选表，在 tune pilot 上比较；不得把任意数写成“已选最优”。未有选参证据时保持机会增强关闭。

数据集分为 tune / ablation / stress / holdout，保存全部 trials 和失败。参数选择先要求全部清除，再比较 mean(T_j/n_j)，辅以距离、检测、换频和最坏表现；效果接近时选稳定、简单、额外动作少的配置。

调参结束才生成 FROZEN_CONFIG.yaml，至少记录 model_version、spec_version、τ 及单位、m、启用支线、case_set_version/hash、selection_metric、selection_rule、freeze_time、代码版本或 source_hash。当前目录非 Git 仓库时不能编造 git_commit。

freeze 后不再依据 holdout 或正式测试结果改参数。若发现正确性问题，记录旧版本失败、新版本与新验证集；已查看的 holdout 不再当新版本未见数据。

### 11.2 四组核心消融

各组只改一个模块，使用同一冻结 case file、同一误差场、同一成功定义和预算；切换模块导致保证条件变化时须注明，不能套用原定理。

| 编号 | Proposed / Baseline | 唯一变化 | 主要指标 |
|---|---|---|---|
| A1 | 冻结主动选点 / 固定几何或 Q2 对照 | 观测位置规则 | 每源观测数、MEC 随次数/时间、T/n |
| A2 | 机会复用 / 专门机动 | 停点与路径复用 | 专用定位距离、总距离、T/n、额外测量成本 |
| A3 | 状态感知 / 每停点机械扫描未清频道 | 频道扫描集合 | 检测/换频次数及耗时、T/n |
| A4 | ΔC/成本 / 最近未完成证书点 | 残余证书点选择 | 证书完成时间、残余距离、T/n |

Q3 A1 更换 MEC 测点后不得继续引用六次界；Q4 的确定性 fallback 在四组中保持一致。额外 Q4 对照为 naive Q3-style completion 与 directional-aware certificate，重点报告漏源/清除率，不只比较时间。

31 点与历史 73 点、MEC 收益与直径收益、Z 内近点与圆心、E2 开关可另设单因素对照。不能把同时改动多个模块的前后演示表解释为某一模块的因果效果。

## 12. Synthetic 与统计口径

误差场满足 ε(S,c)∈[−1°,1°] 且同点同频道固定。至少包含固定随机场、±1° 边界/不利符号场、空间相关结构场。不利场也须在跨方法比较前固定，不能逐算法重新选择有利或不利误差。

场景涵盖 10/16 源、边界、聚簇/分散、不利定向、接收半径两端、近平行 bearing、near 提前触发、空频道和网格退化。case 文件含 case_id、seed、源频道/位置/类型/半径/朝向、error_field_version/hash，在线策略不能读取真值。

官方随机演练不自动构成 matched-case。所有算法读取同一冻结场景文件，分开计虚拟时间与现实运行时间。

统计保留所有失败/超时/verifier FAIL。至少报告案例数、成功数、清除率、mean/median/std 或 IQR、best/worst；成功条件先行，不能仅筛成功子集声称整体更快。相同案例优先报告 paired difference，注明正负方向。不得伪造置信区间。

## 13. 中间证据、Figure 与论断绑定

每 run 保存 config.yaml、provenance.json、actions.csv、observations.csv、trajectory.csv、channel_state_history.jsonl、decision_trace.jsonl、localization_history/、certificate_history/、metrics.json、verifier_report.json、figure_data/。

| 证据 | 必需内容 |
|---|---|
| provenance | 模型/契约/代码版本或哈希、case 与误差场哈希、策略分支、冻结配置哈希、起始时间 |
| actions | step、动作/位置/频道、真实端点、request_id、accepted、前后虚拟时刻、模式/理由、位移、移动/检测/换频/光学/激光成本 |
| observations | 原始反馈、位置、频道、svd_deg、状态前后；拒绝与重试单独标注 |
| decision_trace | READY/ACTIVE/UNKNOWN、候选及 gain/cost、MEC 目标、选中与 tie-break、机会插入、证书增益、剩余预算、fallback 原因 |
| localization_history | 可重建外包几何、面积/直径、MEC 中心/认证半径、Z/选定清除点、观测次数 |
| certificate_history | 频道、时间、见证集合、coverage 定义/面积/增益、采样或认证标识 |
| metrics | T/清除数、事后真源数、清除率、总 T、距离、检测/换频/光学/成功次数、现实时间、失败类型 |

Figure 链为 raw evidence → figure_data → plot script → final figure。图从保存数据重建，交付 PDF/SVG master、PNG preview、CSV/JSON 及脚本；不能从 stdout 人工摘数作唯一数据源。

| Figure | 必须表达/使用的数据 |
|---|---|
| F1 方法闭环 | 冷启动、三模式、停点扫描、发现/证空、有限 fallback、合法结束 |
| F2 定位几何 | 首次楔形、多次约束、MEC、Z 与清除点 |
| F3 Q3 证书 | 无信号点、1000 m 排除盘、已证域与残余 |
| F4 Q4 证书 | 31 点、目标所在三角形、定向半平面、边界/格点退化 |
| F5 收敛 | case、channel、观测序号、virtual_time、MEC、method；Q3 六次界条件明确 |
| F6 消融 | case、variant、metric、value、success，优先 paired difference |
| F7 时间分解 | 互斥的移动/检测/换频/光学/激光项；证书模式耗时另按阶段展示，不能与这些动作项重复相加 |

每个论文 claim 绑定 controlled comparison、metric、case_set、success/failure condition、verifier、figure/table 与降级规则。A1–A4 无稳定改善时保留结果并缩小论断；只降距离不能称总时间更优。确定性命题依靠证明，数值抽查辅助发现反例。

## 14. 验收与重新打开模型的条件

后续验收顺序：Geometry → Certificate → State/Policy toy cases → Tuning → Config freeze → 四组消融 → Holdout synthetic → Official rehearsal → Formal test。未执行的 Gate 标待验，不能沿用历史的测试通过数字。

实现验收要求角度环绕、保守几何、READY/证空无误判、冷启动与批扫记账、有限 ACTIVE/fallback、16 源停止、真实四接口、重试去重、指标可复算、完整 replay、四组 runner 和 Figure 重建、数据隔离全部有当前版本证据。runner 应支持 run/tune/experiment/figures，入口名称依实际代码，不在本文件虚构已存在命令。

实验交付至少包含 tuning/search_space.yaml、tuning/trials.csv、tuning/selection_report.md、FROZEN_CONFIG.yaml、ablation/a1.csv 至 a4.csv 及 summary.csv、tuning_report.md、ablation_report.md、figure_manifest.md、evidence_manifest.md、failure_report.md、paper_ready_tables/ 和 paper_ready_figures/。这些是后续交付要求，不是当前已生成成果清单。

数学主线冻结后，仅因反例、题面冲突、保证条件不成立，或经同案例验证且重新认证的策略改进而修订。新方法默认支线；效率论断与配置必须以实际结果单独定稿。

本版可以作为后续实现与实验的稳定依据。“模型契约已定稿”不等于“没有任何遗漏”，也不等于生产程序和竞赛成绩已获得保证。
