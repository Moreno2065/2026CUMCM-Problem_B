# 4 问题 2：有界误差下的第二检测点主动选择

## 4.1 问题分析：第二点不是“找一个 90° 位置”

问题 2 已知第一检测点 \(S_1\) 及某全向干扰源在该点测得的示向度 \(\hat\theta_1\)，需要选择第二检测点 \(S_2\)，使第二次观测后获得较好的交会定位效果，并给出可供选择的第二检测点区域。

表面上，这似乎只是经典的双站测向几何问题：让两条测向方向尽量接近正交即可。然而，本题比“已知目标位置下的最优传感器布设”多出三个关键不确定性。

第一，**目标距离未知**。一次示向度只提供方位约束，不能确定干扰源与 \(S_1\) 的距离。考虑 \(\pm1^\circ\) 测向误差后，第一次观测留下的不是一条射线，而是一个窄而长的目标可能区域。

第二，**干扰源的实际有效接收半径未知**。题目只给出

\[
1000\le R\le1500\ \mathrm{m},
\]

因此第二点若只追求较大的交会角，可能走得过远而失去信号；若过分靠近 \(S_1\)，又会因基线过短或近共线使定位区域变大。

第三，**测向误差只有确定性边界，没有给出概率分布**。题目规定同一地点重复检测误差在一段时间内保持不变，因此原地重复测量不能通过平均自动消除误差。本文据此采用有界误差集合建模，而不额外假设高斯、均匀或独立同分布噪声。

所以，问题 2 的核心矛盾是

\[
\boxed{
\text{拉开观测基线、改善交会几何}
\quad\Longleftrightarrow\quad
\text{保持对未知目标的可靠可检测性}
}
\]

本文不预先规定某个固定交会角，而是在第一次观测形成的目标不确定集合上，先建立**保证第二次仍可检测的鲁棒行动域**，再直接以问题 1 定义的“交会定位区域直径”为评价指标，选择最坏情况下定位直径尽可能小的第二检测点。

整体建模链为

\[
\boxed{
\text{首次观测}
\rightarrow
\text{目标可能集合}
\rightarrow
\text{鲁棒可检测域}
\rightarrow
\text{第二次可能观测}
\rightarrow
\text{最坏交会直径}
\rightarrow
\text{近优检测点与候选区域}
}
\]

经典 AOA/bearing-only 研究表明，传感器—目标距离和交会几何会显著影响定位精度 [1-3]；有界误差定位研究则说明，在只知道误差边界时，直接维护可行集合是一种自然的处理方式 [4]。本文借鉴这些思想，但主模型完全由本题给出的 \(\pm1^\circ\) 硬误差界和 1000–1500 m 接收距离约束驱动；基于高斯噪声、协方差或 Fisher 信息的结果仅作为几何解释，不作为本题主模型的概率假设 [1-3,5]。

## 4.2 符号、角度约定与建模边界

目标区域为半径 1800 m 的圆盘

\[
\Omega
=
\left\{
X\in\mathbb R^2:\|X-O\|\le1800
\right\}.
\]

第一检测点记为

\[
S_1=(x_1,y_1),
\]

第一次测得的示向度为 \(\hat\theta_1\)。测向误差上界固定为

\[
\varepsilon=1^\circ=\frac{\pi}{180}.
\]

干扰源真实位置记为 \(G\)，其实际有效接收半径记为 \(R\)，有

\[
1000\le R\le1500.
\]

定义圆周角距离

\[
d_{\mathbb S}(\alpha,\beta)
=
\min_{k\in\mathbb Z}
|\alpha-\beta+2k\pi|.
\]

对角度集合 \(A\subset\mathbb S^1\)，定义集合到角度的距离

\[
\operatorname{dist}_{\mathbb S}(A,\beta)
=
\inf_{\alpha\in A}d_{\mathbb S}(\alpha,\beta).
\]

记

\[
u(\theta)=(\cos\theta,\sin\theta)^\mathsf T.
\]

本文只采用以下建模条件：

- 干扰源在两次检测期间位置不变；
- 检测点坐标视为准确；
- 只使用 \(|e|\le\varepsilon\) 的确定性测向误差界；
- 问题 2 的主目标是定位质量，不把移动时间混入主目标；移动代价在问题 3 的在线任务调度中叠加；
- 干扰源必须位于 \(\Omega\) 内，但检测点 \(S_1,S_2\) **不额外限制在 \(\Omega\) 内**。这与后续机器狗允许在目标区域外提交检测位置的规则一致；同时，后文的鲁棒可检测约束本身会把有效候选域限制在有限范围内。

## 4.3 第一次观测把未知目标压缩为一个有界集合

由于 \(S_1\) 已经正常返回示向度而非 `near`，真实目标必须同时满足：

\[
d_{\mathbb S}
\bigl(\arg(G-S_1),\hat\theta_1\bigr)
\le\varepsilon,
\]

\[
5<\|G-S_1\|\le R,
\]

\[
1000\le R\le1500,
\]

以及

\[
G\in\Omega.
\]

对未知 \(R\) 做存在性消元：只要 \(\|G-S_1\|\le1500\)，就存在某个与首次成功检测相容的 \(R\in[1000,1500]\)。于是第一次观测后的目标位置可行集合为

\[
\boxed{
\mathcal A_1
=
\left\{
G\in\Omega:
5<\|G-S_1\|\le1500,
\quad
d_{\mathbb S}
\bigl(\arg(G-S_1),\hat\theta_1\bigr)
\le\varepsilon
\right\}.
}
\tag{1}
\]

集合 \(\mathcal A_1\) 回答的是：

> **在第一次观测之后，真实干扰源还可能位于哪里？**

它同时吸收了首次方位信息、\(\pm1^\circ\) 误差、目标圆域、1500 m 最大接收距离和 5 m `near` 阈值。

这里必须区分两个概念：\(\mathcal A_1\) 是用于后续决策的**物理状态可行集**；问题 1 的交会定位区域则是由测向角锥本身定义的**纯测向几何区域**。后文计算问题 1 的定位直径时，不把 \(\Omega\)、接收距离或 `near` 半径重新截入交会多边形，以保证问题 1—问题 2 的指标定义一致。

## 4.4 利用“第一次已经收到信号”构造鲁棒可检测域

如果完全忽略第一次成功检测所携带的信息，只依据题目给出的最小接收半径 1000 m，就会要求第二点对所有候选目标都位于 1000 m 内，产生不必要的保守性。

事实上，对任意 \(G\in\mathcal A_1\)，第一次已经在 \(S_1\) 成功接收到信号，因此真实接收半径还必须满足

\[
R\ge\|G-S_1\|.
\]

与 \(R\ge1000\) 合并，可得到在目标位置 \(G\) 已知但 \(R\) 未知时，与首次观测相容的最小接收半径

\[
\boxed{
R_{\min}^{\rm comp}(G)
=
\max\{1000,\|G-S_1\|\}.
}
\tag{2}
\]

如果要求第二检测点在**所有与第一次观测相容的 \((G,R)\)** 下都能继续接收到该全向干扰源，则对每个 \(G\in\mathcal A_1\) 必须满足

\[
\|S_2-G\|
\le R_{\min}^{\rm comp}(G).
\]

因此定义

\[
\boxed{
\mathcal C_{\rm rec}
=
\bigcap_{G\in\mathcal A_1}
B\!\left(
G,\max\{1000,\|G-S_1\|\}
\right).
}
\tag{3}
\]

### 命题 1：\(\mathcal C_{\rm rec}\) 的含义

\(\mathcal C_{\rm rec}\) 不是“所有可能收到信号的点”的集合，而是：

\[
\boxed{
\text{对所有与首次观测相容的目标位置和接收半径，均保证第二次可检测的点集。}
}
\]

这个定义在“**第二次必须无条件保证继续收到信号**”这一稳健要求下是精确的，而不是额外拍出的充分条件。

此外，\(S_1\in\mathcal C_{\rm rec}\)，因为对任意 \(G\in\mathcal A_1\)，都有

\[
\|S_1-G\|
\le
\max\{1000,\|G-S_1\|\},
\]

因此 \(\mathcal C_{\rm rec}\neq\varnothing\)。

需要同时说明它的策略边界：如果允许第二次走到 \(\mathcal C_{\rm rec}\) 外，并在 `no_signal` 后继续利用“负信息”更新目标集合，那么可以设计更激进的多步序贯策略。问题 2 为了给出单步、可解释且具有确定性保证的第二点选择规则，主模型采用 \(\mathcal C_{\rm rec}\)；这种保守性将在问题 3 的在线搜索中通过序贯观测进一步释放。

### 4.4.1 连续鲁棒约束的径向约化

为了判断某候选点 \(X\) 是否属于 \(\mathcal C_{\rm rec}\)，将目标写为

\[
G=S_1+\rho u(\theta).
\]

在某个可行方向 \(\theta\) 上，射线与 \(\Omega\)、\(5<\rho\le1500\) 共同给出一个可能为空的单一区间

\[
\rho\in
I(\theta)
=
[\rho_{\rm lo}(\theta),\rho_{\rm hi}(\theta)].
\]

对给定候选点 \(X\)，定义约束违反函数

\[
g_X(\rho,\theta)
=
\|X-S_1-\rho u(\theta)\|
-
\max\{1000,\rho\}.
\]

则

\[
X\in\mathcal C_{\rm rec}
\iff
\sup_{\theta}
\sup_{\rho\in I(\theta)}
 g_X(\rho,\theta)
\le0.
\]

固定 \(\theta\) 后，当 \(\rho\le1000\) 时，\(g_X\) 关于 \(\rho\) 为凸函数，区间最大值出现在端点；当 \(\rho\ge1000\) 时，

\[
\frac{\partial g_X}{\partial\rho}
=
\frac{
\rho-\langle X-S_1,u(\theta)\rangle
}{
\|X-S_1-\rho u(\theta)\|
}
-1
\le0,
\]

故该段单调不增。因此固定方向上只需检查

\[
\boxed{
\mathcal R(\theta)=
\begin{cases}
\{\rho_{\rm lo},\rho_{\rm hi}\},
&\rho_{\rm hi}\le1000,\\[3pt]
\{\rho_{\rm lo},1000\},
&\rho_{\rm lo}<1000<\rho_{\rm hi},\\[3pt]
\{\rho_{\rm lo}\},
&\rho_{\rm lo}\ge1000.
\end{cases}
}
\tag{4}
\]

于是原本对二维连续目标集合的检查被约化为一个一维角度最大化问题：

\[
\sup_{\theta}
\max_{\rho\in\mathcal R(\theta)}
 g_X(\rho,\theta).
\]

这里还有一个值得单独指出的几何性质：**对某个已经可行的方向 \(\theta\)，一旦进入 \(\rho\ge1000\) 的深部区间，约束违反函数便单调不增。** 因而在该方向内部，\(\rho=1500\) 的深端不会成为比“进入深部区间的最近点”更严格的 \(\mathcal C_{\rm rec}\) 约束。换言之，1500 m 外端不是一个需要单独枚举的“深端最坏 witness”。

但这**不等于**可以从模型中删除 1500 m 上限。\(\rho\le1500\) 仍然参与定义 \(\mathcal A_1\) 的角向支撑范围；尤其当 \(S_1\) 靠近或位于 \(\Omega\) 外部时，它可能决定某些方向是否存在与首次观测相容的目标。因此，更准确的结论是：

\[
\boxed{
1500\text{ m 深端在固定可行方向的 }\mathcal C_{\rm rec}\text{ 径向最坏约束中冗余，}
\quad
\text{但在 }\mathcal A_1\text{ 的全局几何定义中并不冗余。}
}
\]

当 \(\Omega\) 的圆弧参与截断时，\(\rho_{\rm lo}(\theta)\)、\(\rho_{\rm hi}(\theta)\) 会随 \(\theta\) 变化。实现中对这些圆弧段保留解析驻点候选并配合独立数值复核，不把“固定半径圆弧只查端点/对跖点”错误推广到所有 \(\Omega\) 截断情形。

## 4.5 `near` 状态与第二次可能示向集合

第二次检测并不一定返回一个示向角。按照题意，当真实目标满足

\[
\|G-S_2\|\le5
\]

时，测向机返回 `near`，机器狗可直接进行光学精确定位与清除。因此对给定第二点，先把首次可行集分成

\[
\mathcal A_1^{\rm near}(S_2)
=
\mathcal A_1\cap B(S_2,5)
\]

和

\[
\boxed{
\mathcal A_1^{\rm dir}(S_2)
=
\left\{
G\in\mathcal A_1:\|G-S_2\|>5
\right\}.
}
\tag{5}
\]

若真实目标恰好落在 \(\mathcal A_1^{\rm near}(S_2)\) 中，则第二次观测直接进入 `near` 成功分支，不再产生 bearing；这部分状态的处理结果优于继续做角度交会。因此，**最坏定位直径只需要在仍会产生 direction 的补集 \(\mathcal A_1^{\rm dir}\) 上评价。**

由这些目标产生的真实第二方位集合为

\[
\Theta_2^{\rm dir}(S_2)
=
\left\{
\arg(G-S_2):
G\in\mathcal A_1^{\rm dir}(S_2)
\right\}.
\tag{6}
\]

由于式 (5) 使用严格不等式，该集合可能不是闭集。为刻画最坏情形的极限方位，定义

\[
\overline\Theta_2^{\rm dir}(S_2)
=
\overline{\Theta_2^{\rm dir}(S_2)}.
\tag{7}
\]

第二地点自身仍存在 \(\pm\varepsilon\) 测向误差，因此极限闭合后的所有可能读数集合为

\[
\boxed{
\widehat\Theta_2^{\rm dir}(S_2)
=
\overline\Theta_2^{\rm dir}(S_2)
\oplus[-\varepsilon,\varepsilon].
}
\tag{8}
\]

这里采用闭包并不是把距离恰好为 5 m 的 `near` 点错误当成真实 bearing，而是把实际 direction 序列可能逼近的极限方向纳入 worst-case supremum。后文在严格的有界性交会安全门内，\(D_{\rm Q1}(S_2,\beta)\) 对合法 \(\beta\) 分段连续，因此使用闭合集合可以稳定求取极限最坏值。

从代码完备性出发，仍保留极端情形

\[
\mathcal A_1^{\rm dir}(S_2)=\varnothing.
\tag{9}
\]

即所有兼容目标都处于 5 m `near` 范围。对通常具有宏观径向深度的正面积 \(\mathcal A_1\)，这一情形一般不会出现；它主要用于处理目标域强截断或零/低维退化几何。若发生，则可直接进入光学清除，定义

\[
L_{\rm near}=0.
\tag{10}
\]

因此 `all-near` 是一个**完备性分支而非主叙事场景**；问题 2 的实际最坏情况通常由 \(\mathcal A_1^{\rm dir}\) 上的 direction 分支决定。

## 4.6 与问题 1 完全一致的交会定位直径

对正常返回的第二示向读数 \(\beta\)，仍严格沿用问题 1 的交会定位定义。

为避免锥顶处 \(\arg(0)\) 的记号问题，将单次测向角锥定义为

\[
\mathcal K(S,\theta)
=
\left\{
S+t u(\phi):
 t\ge0,
\ d_{\mathbb S}(\phi,\theta)\le\varepsilon
\right\}.
\]

两次测向形成的纯角度交会区域为

\[
\boxed{
P_{\rm Q1}(S_2,\beta)
=
\mathcal K(S_1,\hat\theta_1)
\cap
\mathcal K(S_2,\beta).
}
\tag{11}
\]

注意：式 (11) **不再加入** \(\Omega\)、5 m、1000 m 或 1500 m 等物理约束。这样，问题 2 评价的正是问题 1 所定义的同一个交会定位区域，不会出现“选点使用一种区域、评价又换成另一种区域”的指标错位。

定义其直径

\[
\boxed{
D_{\rm Q1}(S_2,\beta)
=
\sup_{X,Y\in P_{\rm Q1}(S_2,\beta)}
\|X-Y\|.
}
\tag{12}
\]

若交会区域无界，则规定

\[
D_{\rm Q1}(S_2,\beta)=+\infty.
\]

### 4.6.1 何时交会区域一定有界？

两次测向锥的方向区间分别为

\[
[\hat\theta_1-\varepsilon,\hat\theta_1+\varepsilon]
\]

和

\[
[\beta-\varepsilon,\beta+\varepsilon].
\]

当

\[
\boxed{
d_{\mathbb S}(\beta,\hat\theta_1)>2\varepsilon
}
\tag{13}
\]

时，两锥不存在共同无穷方向；对于本模型中由真实目标产生的非空交会，区域因此有界。

但选择 \(S_2\) 时还不知道第二次实际误差。真实第二方位 \(\theta_2\) 到第一次读数 \(\hat\theta_1\) 若只比 \(2\varepsilon\) 大一点，第二地点再叠加一个最坏的 \(\pm\varepsilon\) 误差后，实际读数 \(\beta\) 仍可能落回退化区。因此需要再预留一个 \(\varepsilon\) 安全裕量。

若不是 all-near，定义

\[
\boxed{
\operatorname{dist}_{\mathbb S}
\left(
\overline\Theta_2^{\rm dir}(S_2),
\hat\theta_1
\right)
>3\varepsilon.
}
\tag{14}
\]

其推导来自三角不等式：任意真实第二方位 \(\theta_2\) 与第二读数 \(\beta\) 满足

\[
d_{\mathbb S}(\beta,\hat\theta_1)
\ge
 d_{\mathbb S}(\theta_2,\hat\theta_1)-\varepsilon
>2\varepsilon.
\]

于是所有可能第二读数都避开无界交会。

反之，如果式 (14) 不成立，则存在实际或极限真实方位使第二读数可以进入或任意逼近 \(2\varepsilon\) 的临界平行状态：前者直接产生无界交会，后者使定位直径无上界。因此，对非 all-near 点，式 (14) 正好对应“最坏定位直径保持有限”的统一安全门。

据此定义可接受行动域

\[
\boxed{
\mathcal C_{\rm adm}
=
\left\{
S_2\in\mathcal C_{\rm rec}:
\mathcal A_1^{\rm dir}(S_2)=\varnothing
\ \text{或}\
\operatorname{dist}_{\mathbb S}
\left(
\overline\Theta_2^{\rm dir}(S_2),
\hat\theta_1
\right)>3\varepsilon
\right\}.
}
\tag{15}
\]

本题 \(\varepsilon=1^\circ\)，因此真实第二方位相对第一次读数需保留严格的 \(3^\circ\) 退化安全裕量。

还需区分另一类几何退化：当第二示向接近

\[
\hat\theta_1+\pi
\]

时，两条视线近似反向共线。此时两角锥的交集通常仍是**有界**的，因此它不属于式 (15) 所排除的“共同无穷方向”退化；但交会角的正弦接近 0，定位区域会变成长而窄的梭形，直径显著增大。本文不把 \(180^\circ\) 邻域硬删出 \(\mathcal C_{\rm adm}\)，而交由 \(Q(S_2)\) 的 minimax 目标自然惩罚。这样可避免把“有界性约束”和“定位质量偏好”混成同一个硬门。

## 4.7 最坏定位直径驱动的稳健主动选点模型

选择 \(S_2\) 时，真实目标位置、真实第二方位和第二地点测向误差都未知。若只在某个假设目标位置上优化交会角，可能得到平均几何很好、但对 \(\mathcal A_1\) 远端或边缘目标严重退化的第二点。

因此，对 all-near 点定义

\[
Q(S_2)=0.
\]

否则定义

\[
\boxed{
Q(S_2)
=
\max_{\beta\in\widehat\Theta_2^{\rm dir}(S_2)}
D_{\rm Q1}(S_2,\beta).
}
\tag{16}
\]

若 \(S_2\notin\mathcal C_{\rm adm}\)，则约定 \(Q(S_2)=+\infty\)。

于是问题 2 的主模型为

\[
\boxed{
Q^*
=
\inf_{S_2\in\mathcal C_{\rm rec}}Q(S_2),
\qquad
S_2\ \text{应选择在 }Q(S_2)\text{ 尽可能接近 }Q^*\text{ 的位置。}
}
\tag{17}
\]

这个 minimax 指标同时处理三件事：

- **可检测性**：\(\mathcal C_{\rm rec}\) 保证所有兼容目标状态下都能继续接收；
- **几何退化**：\(3\varepsilon\) 门限排除所有可能读数下的近平行无界交会；
- **定位质量**：直接最小化问题 1 定义的最坏交会区域直径。

因此，本文所谓“较好的定位效果”被具体化为一个与问题 1 完全统一、且不依赖额外概率假设的可计算量，而不是人为规定“第二次必须与第一次形成 \(90^\circ\)”。

需要注意：式 (17) 给出了理论优化问题；实际程序通过二维数值搜索获得的是**数值近优解** \(\widehat S_2\)，除非后续额外建立全局最优证书，否则论文不得把它表述为已证明的全局最优点。

## 4.8 为什么经典的 \(90^\circ\) 规则仍然有用，但只能当解释和基线

设真实目标到两检测点距离分别为 \(d_1,d_2\)，两条真实视线夹角为 \(\gamma\)。当目标距离两个锥顶较远且 \(\varepsilon\) 较小时，可将两个角锥在目标附近一阶线性化为横向半宽约为

\[
w_i\approx d_i\varepsilon
\]

的两条误差带。

两误差带交集近似为平行四边形，其直径一阶近似为

\[
\boxed{
D_{\rm loc}
\approx
\frac{2\varepsilon}{\sin\gamma}
\sqrt{
 d_1^2+d_2^2
 +2d_1d_2|\cos\gamma|
}.
}
\tag{18}
\]

当 \(d_1,d_2\) 固定时，上式在

\[
\gamma=90^\circ
\]

处取得最小值。因此，正交交会确实是合理的局部几何规律，与经典 AOA/bearing-only 最优几何研究相符 [1-2]。

然而，本题移动 \(S_2\) 时 \(d_2\) 与 \(\gamma\) 会同时变化，真实目标又只知道属于 \(\mathcal A_1\)。此外，靠近锥顶时实际定位区域由有限角锥直接截断，远场误差带近似会失效。因此

\[
\boxed{
90^\circ\text{ 是局部解释和 baseline，不能替代完整的鲁棒 minimax 模型。}
}
\]

这也是本文不直接以 FIM/CRLB 作为主指标的原因：相关文献中的协方差或 Fisher 信息模型通常建立在随机噪声和局部估计框架上 [1-3,5]，而本题明确提供的是确定性的 \(\pm1^\circ\) 误差边界。

## 4.9 内层最坏 bearing：事件分割 + 数值根隔离 + 独立复核

对给定 \(S_2\)，式 (16) 只剩一维角变量 \(\beta\)。纯固定步长扫描容易在近平行区域或包络切换附近漏掉窄峰，而把全部驻点和切换点写成高阶闭式多项式又会增加不必要的数值脆弱性。因此本文采用“**有限几何事件用于分段，段内极值用数值根隔离/自适应细分求取，最终再用独立扫描复核**”的混合策略。

随着 \(\beta\) 变化，问题 1 交会多边形由两组角锥边界决定。实现中显式处理以下候选：

1. **E1：允许读数区间端点**；
2. **E2：锥顶事件**，即 \(S_1\) 进入或离开第二角锥；
3. **E3：边界平行事件**，包括相差 \(0\) 或 \(\pi\) 的直线平行关系及其合法单侧极限；
4. **E4：固定拓扑段内最远点对距离的驻点**；
5. **E5：不同最远点对距离函数的上包络切换点**。

E1--E3 可直接由几何关系给出；E4--E5 不在正文中声称具有简单闭式表达式。程序在相邻刚性事件之间保持顶点组合固定，利用导数/差值函数的**自适应数值根隔离**寻找候选根，并将所有候选重新送入问题 1 几何求解器计算真实直径。

更重要的是，E1--E5 候选器不单独承担“绝不漏峰”的理论承诺。最终 Hero 点及关键候选区域边界必须再通过一条**不复用 E4/E5 根查找逻辑**的独立高密度/自适应角度扫描进行复核。若独立扫描发现更大的 \(D_{\rm Q1}\)，则以更大值为准并触发局部精修或报错，而不是继续相信原候选表。

因此本文的内层求解可以概括为

\[
\boxed{
\text{几何事件分段}
+
\text{数值根隔离}
+
\text{独立扫描验证}
}
\]

这与实际实现一致，也避免把一个数值求解器包装成不存在的高阶解析闭式定理。

## 4.10 外层二维搜索与“数值近优”表述

外层变量仅为 \(S_2=(x_2,y_2)\)。由于 \(Q(S_2)\) 可能非凸、非光滑，并在退化安全门附近迅速增大，本文采用确定性的粗网格—局部剖分—模式搜索三阶段数值搜索。

为得到有限搜索窗口，程序从 \(\mathcal C_{\rm rec}\) 的若干**必要圆盘约束**出发，取这些圆盘轴对齐包围盒的交集，得到

\[
\boxed{
\mathcal B_{\rm search}\supseteq\mathcal C_{\rm rec}.
}
\]

该矩形只是一个安全的搜索包围盒，不是 \(\mathcal C_{\rm rec}\) 的精确边界；由于只使用必要约束的包围盒，它可能偏松，但不会把真实 \(\mathcal C_{\rm rec}\) 内点误删。对 \(\mathcal B_{\rm search}\) 内的每个实际候选点，仍通过独立的 \(\mathcal C_{\rm rec}\) 成员判定器和式 (15) admissibility 门进行过滤。

推荐数值流程为：

- 在 \(\mathcal B_{\rm search}\) 上生成确定性粗网格与若干解析/对称初值；
- 对所有点重新计算 \(\mathcal C_{\rm rec}\)、admissibility 和 \(Q(S_2)\)；
- 对低值区域进行局部空间细分；
- 用多方向无导数模式搜索继续压低 incumbent；
- 固定最终 incumbent 后，对其局部邻域、镜像点（若理论上应对称）和更密证据网格进行复查。

由于当前没有覆盖整个二维域的严格下界或 branch-and-bound 证书，论文只声称获得

\[
\boxed{
\widehat S_2\text{：在冻结搜索协议下经独立复核稳定的数值 incumbent}
}
\]

及

\[
\widehat Q=Q(\widehat S_2),
\]

而不宣称“已证明全局最优”。

题面没有给出具体的 \(S_1\) 与 \(\hat\theta_1\)，因此不存在一个脱离输入的唯一数值坐标 \(\widehat S_2\)，也不存在题面指定的唯一数值 \(\widehat Q\)。问题 2 的正式输出应理解为参数化映射

\[
\boxed{
(S_1,\hat\theta_1)
\longmapsto
\left(
\widehat S_2(S_1,\hat\theta_1),
\widehat Q(S_1,\hat\theta_1)
\right).
}
\]

获得实际首次观测后，再由数值求解器在有限搜索协议下计算对应的推荐点和目标值。这里的 \(\widehat S_2\) 是搜索得到的数值 incumbent，\(\widehat Q=Q(\widehat S_2)\) 是其实际评价值；理论最优值仍记为 \(Q^*=\inf_{S_2\in\mathcal C_{\rm adm}}Q(S_2)\)，在没有全局证书时不宣称 \(\widehat Q=Q^*\)。后文代表性工况中的坐标、直径和面积只用于说明算法可执行并检验几何性质，不能表述为题目给定数据或问题 2 的固定答案。

## 4.11 从一个近优点扩展为题目要求的“候选区域”

题目并不只要求给出一个第二检测点，还要求给出候选区域。并且进入问题 3 后，机器狗还要兼顾其它频道、后续清除目标和整体路径，因此把答案压缩成唯一坐标反而会降低后续调度自由度。

理论上，以数值 incumbent \(\widehat Q\) 为基准定义近优水平集

\[
\boxed{
\widehat{\mathcal C}_{\rm good}(\eta)
=
\left\{
S_2\in\mathcal C_{\rm adm}:
Q(S_2)\le(1+\eta)\widehat Q
\right\}.
}
\tag{19}
\]

正文固定以

\[
\eta=5\%
\]

作为主展示尺度，同时报告 \(1\%,2\%,10\%\) 的敏感性。

需要把“数学定义”和“程序画出来的区域”区分开。当前实现没有 \(Q(S_2)\) 的全局 Lipschitz/区间上界，因此不能证明每一个二维网格单元都整体位于式 (19) 中。程序采用自适应网格对水平集进行**数值近似**：对靠近阈值、可行性边界和 Hero 的单元重点细分，并根据角点与中心采样值判断其数值归属。记实际绘制结果为

\[
\widetilde{\mathcal C}_{\rm good}^{\rm num}(\eta).
\]

它是式 (19) 的数值近似，而**不是带集合包含证书的严格内/外逼近**。因此论文和图例统一使用“numerical near-optimal region / 数值近优候选区域”，并通过提高基础分辨率、减小目标单元尺寸来检查面积与边界是否稳定。

这一表述比把像素/网格区域直接称为“精确候选域”更严谨，也与实际代码输出中的 `numerical_candidate_good_region_not_proof` 保持一致。

## 4.12 问题 2 的可执行选择策略

将上述模型压缩成机器狗可调用的单步策略如下。

### 算法 1：有界误差下的第二检测点选择

**输入**：第一检测点 \(S_1\)、第一次示向度 \(\hat\theta_1\)、误差界 \(\varepsilon=1^\circ\)。  
**输出**：数值近优点 \(\widehat S_2\)、相对该 incumbent 的近优水平集数值近似 \(\widetilde{\mathcal C}_{\rm good}^{\rm num}(5\%)\) 及其它阈值敏感性区域。

1. 根据式 (1) 构造首次观测目标集合 \(\mathcal A_1\)；
2. 根据式 (2)–(4) 建立 \(\mathcal C_{\rm rec}\) 的成员判定器；
3. 对候选 \(S_2\)：
   - 构造 partial-near 集 \(\mathcal A_1^{\rm near}\) 与 direction 集 \(\mathcal A_1^{\rm dir}\)；
   - 若退化情形下 \(\mathcal A_1^{\rm dir}=\varnothing\)，置 \(Q(S_2)=0\)；
   - 否则构造 \(\overline\Theta_2^{\rm dir}(S_2)\)；
   - 若 \(\operatorname{dist}_{\mathbb S}(\overline\Theta_2^{\rm dir},\hat\theta_1)\le3\varepsilon\)，置 \(Q(S_2)=+\infty\)；
   - 否则采用 E1--E5 事件分段、数值根隔离和独立扫描验证求得最坏交会直径 \(Q(S_2)\)；
4. 在安全搜索盒 \(\mathcal B_{\rm search}\) 内进行确定性二维搜索，每个点都重新通过 \(\mathcal C_{\rm rec}\) 与 admissibility 判定，得到 \(\widehat S_2\)；
5. 对 \(\eta=1\%,2\%,5\%,10\%\) 自适应采样式 (19)，构造数值候选区域 \(\widetilde{\mathcal C}_{\rm good}^{\rm num}(\eta)\)；
6. 用不共享 E4/E5 根查找逻辑的独立角度扫描、问题 1 几何重算和分辨率加密实验复核最终结果。

这给出了题目所要求的完整“**选择策略 + 候选区域**”，而不是一句经验性的“尽量形成直角交会”。

## 4.13 与问题 3 的具体接口

问题 2 最终向问题 3 输出三个几何对象：

\[
\boxed{\mathcal A_1}
\]

——当前目标位置的有界知识；

\[
\boxed{\mathcal C_{\rm rec}}
\]

——若要求下一次一定继续检测到该全向源，可安全行动的区域；

\[
\boxed{\widetilde{\mathcal C}_{\rm good}^{\rm num}(5\%)}
\]

——由式 (19) 的 5% 理论水平集经自适应数值采样得到的下一观测候选区域。

进入问题 3 后，不再要求机器狗机械前往 \(\widehat S_2\)。设机器狗当前既定任务路径产生一组沿途候选停点 \(\mathcal C_{\rm route}\)，则优先选择

\[
S_{2,\rm Q3}
\in
\widetilde{\mathcal C}_{\rm good}^{\rm num}(5\%)
\cap
\mathcal C_{\rm route},
\]

从而复用原本就要发生的移动形成测向基线。若交集为空，再在数值近优区域中选择附加移动代价最小的点，例如

\[
\boxed{
S_{2,\rm Q3}
\in
\arg\min_{S_2\in\widetilde{\mathcal C}_{\rm good}^{\rm num}(5\%)}
\|S_2-S_{\rm current}\|
}
\]

或在已知下一任务点 \(S_{\rm next}\) 时最小化插入路径增量。这样，\(\eta\) 实质上提供了“允许少量定位性能损失以换取显著机动时间节省”的离散 Pareto 自由度，而无需在 Q2 主目标中事先人为设定移动时间权重。

因此 Q2 与 Q3 的分工非常明确：

\[
\boxed{
\text{Q2 决定“哪些位置在定位几何上值得去”}
}
\]

\[
\boxed{
\text{Q3 决定“结合全局任务以后到底去其中哪个”}
}
\]

这避免在问题 2 中提前混入多频道路径代价，又使问题 2 的结果能够直接成为问题 3 的主动定位 primitive。

## 4.14 模型特点、保守性与适用边界

### （1）与题目给定误差形式一致

主模型只使用

\[
|e|\le1^\circ
\]

的硬边界，不人为增加 Gaussian、uniform 或空间独立等题面没有给出的概率假设。因此 \(\mathcal A_1\)、\(\mathcal C_{\rm rec}\) 和 \(Q(S_2)\) 都具有明确的最坏情形含义。

### （2）充分利用首次成功检测这一“隐含观测”

第二点可检测约束没有机械采用统一 1000 m 半径，而是利用

\[
R\ge\|G-S_1\|
\]

构造每个候选目标对应的最小兼容接收半径，从而减少无谓保守性。

### （3）Q1—Q2 指标严格统一

Q2 直接优化问题 1 的交会定位区域直径，不在选点阶段另造一个与最终评价不一致的代理指标。\(90^\circ\) 交会角只作为解释和基线。

### （4）显式处理 `near` 与近平行退化

`near` 被视为终止成功状态；\(3\varepsilon\) 安全门则保证所有可能第二读数都不会落入两锥具有共同无穷方向的退化区域。

### （5）主模型是单步鲁棒策略，不是完整的多步信息策略

\(\mathcal C_{\rm rec}\) 要求第二次无条件继续可检测，因此相对允许 `no_signal` 并利用负信息继续决策的多步策略更保守。本文保留这一选择，是因为问题 2 要求的是清晰可解释的第二点策略；更激进的序贯搜索在问题 3 中处理。

### （6）数值结果只声称“近优稳定”，不虚构全局证书

外层目标可能非凸、非光滑。没有严格全局下界或 Lipschitz 证书时，只报告经独立加密验证的数值近优解及近优区域。

## 5.3 与简单几何基线比较

本文模型的价值不能靠“公式更复杂”证明，必须与无需完整 minimax 的可解释几何策略同口径比较。基线全部使用同一个 Q2 evaluator 重新计算 \(\mathcal C_{\rm rec}\)、admissibility 与最终 \(Q\)，禁止给基线换评价标准。

### B1：中心射线中点的 90° 启发式

在首次示向轴中心方向上取可行径向区间 \([\rho_{\rm lo},\rho_{\rm hi}]\) 的中点作为名义目标 \(G_0\)，然后构造与 \(S_1G_0\) 正交、且 \(\|S_2-G_0\|=\|S_1-G_0\|\) 的第二点。对称两侧同时评价，取其中更优者作为对 baseline 有利的报告值。该方法只体现经典 \(90^\circ\) 局部几何，不针对整个 \(\mathcal A_1\) 做 worst-case 优化。

### B2：中心射线解析 max-min-angle 启发式

在不受 \(\Omega\) 截断的中心标准工况下，进一步对中心射线上的近、远端目标构造解析 max-min-angle 点，作为“只优化最坏交会角、忽略完整二维楔宽和最终多边形直径”的更强几何基线。若进入边界截断工况，该解析公式不再具有原来的严格解释，应明确标记为 canonical heuristic，不能经过投影/裁剪后仍宣称是解析最优角度基线。

### Proposed：完整有界误差 minimax

本文方法使用完整 \(\mathcal A_1\)、可靠接收约束、partial-near、admissibility 和问题 1 直径指标进行求解。

比较表：

| 方法 | 最坏定位直径 / m | \(\mathcal C_{\rm rec}\) 可行 | admissible | 第二点移动距离 / m |
|---|---:|---|---|---:|
| B1：90° 中点启发式 | 待填 | 待填 | 待填 | 待填 |
| B2：中心射线 max-min-angle | 待填 | 待填 | 待填 | 待填 |
| 本文稳健 minimax | 待填 | 是 | 是 | 待填 |

若本文模型数值更优，只据实写“降低了最坏定位直径”；若差距较小，则强调它在二维目标深度不确定性、未知接收半径和测向硬误差界下提供了统一 worst-case 评价，而不能硬写“显著提升”。

## 5.4 独立验证协议

最终结果至少通过以下验证：

### V1：鲁棒接收约束验证

检查

\[
\widehat S_2\in\mathcal C_{\rm rec},
\]

并用独立高密度 \((\theta,\rho)\) 采样复核

\[
\|\widehat S_2-G\|
\le
\max\{1000,\|G-S_1\|\}
\]

对所有采样目标成立。

### V2：\(3\varepsilon\) 有界性门验证

检查

\[
\operatorname{dist}_{\mathbb S}
(\overline\Theta_2^{\rm dir},\hat\theta_1)
>3\varepsilon,
\]

并显式测试接近临界值时 \(Q(S_2)\) 的快速增大趋势。

### V3：内层最坏 bearing 交叉验证

对 Hero、两个基线、候选区边界点和随机可行点，用**不调用 E4/E5 根隔离器**的独立角度扫描/局部精修器计算

\[
Q_{\rm verify}(S_2)
=
\max_{\beta\in\widehat\Theta_2^{\rm dir}}D_{\rm Q1}(S_2,\beta).
\]

报告

\[
\Delta_Q=Q_{\rm verify}-Q_{\rm main}
\]

以及扫描分辨率加倍后的收敛变化。若 verifier 找到超过主求解结果容差的更大值，则必须提升该值并重新触发外层评价，不能只把差异写进 limitation。

### V4：问题 1 几何独立重算

使用与主求解器不同的几何路径重新构造 \(P_{\rm Q1}\) 和直径，避免主算法与 verifier 共用同一个错误实现。

### V5：退化测试

至少覆盖：

- 方位角跨 \(0^\circ/360^\circ\)；
- \(\beta\) 逼近 \(2\varepsilon\) 平行门；
- `near` 边界 \(\|G-S_2\|=5\)；
- \(\Omega\) 圆弧截断首次楔形；
- \(S_1\) 位于 \(\Omega\) 内与外；
- 定位区域退化为极小多边形或边界切触；
- 对称场景下两侧解的一致性。

### V6：外层搜索与候选区域分辨率稳定性

改变粗网格、空间剖分深度、局部精修初值，以及候选区域的基础分辨率/目标单元尺寸，报告：

\[
\max_j
\frac{Q(\widehat S_{2,j}^*)-\min_k Q(\widehat S_{2,k}^*)}
{\min_k Q(\widehat S_{2,k}^*)}
\]

并检查不同设置得到的 \(\widehat Q\)、Hero 坐标和 5% 数值候选区域面积/边界是否趋于稳定。由于候选区域没有集合包含证书，分辨率收敛是其可信度的必要证据。

# 7 问题 2 的最终回答

题面只给出输入类型，即第一检测点 \(S_1\) 和在该点测得的示向度 \(\hat\theta_1\)，没有给出具体数值，所以问题 2 不存在对所有情形通用的固定第二检测点坐标。第二检测点必须随首次观测动态确定。

首先由 \((S_1,\hat\theta_1)\) 构造首次观测后的目标可行集合 \(\mathcal A_1\)，再利用首次已经成功收到信号这一事实，构造保证第二次仍能检测到干扰源的鲁棒可检测域 \(\mathcal C_{\rm rec}\)。在其中排除可能使两次示向交会区域无界的点，得到可接受行动域 \(\mathcal C_{\rm adm}\)。

对任意候选点，先按终止状态和可接受行动域定义目标函数：

\[
Q(S_2)
   =
\begin{cases}
  +\infty, & S_2\notin\mathcal C_{\rm adm},\\[1mm]
  0, & \mathcal A_1^{\rm dir}(S_2)=\varnothing,\\[1mm]
  \displaystyle\max_{\beta\in\widehat\Theta_2^{\rm dir}(S_2)}
  D_{\rm Q1}(S_2,\beta), & \text{otherwise}.
\end{cases}
\]

因此第二检测点的选择策略为

\[
\boxed{
\widehat S_2
\in
\operatorname*{arg\,min}_{S_2\in\mathcal E(S_1,\hat\theta_1)}
Q(S_2),
\qquad
\widehat Q=Q(\widehat S_2),
}
\]

其中 \(\mathcal E(S_1,\hat\theta_1)\subset\mathcal C_{\rm adm}\) 是冻结搜索协议实际评估过的有限候选集。连续域上的理论问题仍是式 (17) 的 \(Q^*=\inf Q\)，数值搜索不自动提供全局最优证书。

为避免把答案压缩成一个对路径调度过于刚性的单点，以允许相对最优值增加 \(\eta\) 的近优水平集作为题目要求的候选区域：

\[
\boxed{
\widehat{\mathcal C}_{\rm good}(\eta)
=
\left\{
S_2\in\mathcal C_{\rm adm}:
Q(S_2)\le(1+\eta)\widehat Q
\right\},
\qquad
\widehat Q=Q(\widehat S_2).
}
\]

正文取 \(\eta=5\%\) 作为主要候选区域，并以 \(1\%,2\%,10\%\) 作敏感性分析。这里的“5%”是相对已找到 incumbent \(\widehat Q\) 的候选阈值；除非另有全局最优证书，不能把它解释为相对未知全局最优值 \(Q^*\) 的误差保证。由于实际程序通过有限分辨率的自适应采样构造该水平集，程序输出应称为数值近优候选区域 \(\widetilde{\mathcal C}_{\rm good}^{\rm num}(\eta)\)。由此，问题 2 的完整答案是“根据首次观测最小化最坏交会定位直径，并输出其近优水平集”，而不是一个预先冻结的经验坐标。代表性算例只负责验证该策略和求解器。
