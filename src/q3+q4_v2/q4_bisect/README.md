# q4-bisect

Q4 的独立 CLI 实验策略。它沿用 `learned` 的发现、25 点证书、滚动调度和
有限兜底；确认 16 个存在频道后，当某个 ACTIVE 连续四次没有有效收缩时，
以可证明的中段双探点抢在昂贵光学兜底之前修复定位。这个观测门控使 10--15
源场景保持生产策略；所有条件都来自在线状态。

每轮根据最近一次 `direction` 的锚点、方向和当前可行多边形计算纵深上界
`D`，测量 `D/2` 截面两端。任一点收到信号便立即重新规划；两个点均为
`no_signal` 时，认证裁剪远端半区。理由是：若源在远端，正观测锚点到源的
线段必穿过两个探点之间；定向接收半平面的线性约束保证两个探点至少有一个
位于可见侧，而两点到所有远端候选的距离都小于 1000 米。这与估计源朝向
无关。首次两个点的间距不超过约 26.2 米。

```powershell
python -X utf8 src/q3+4_v2/run.py --mode q4 --sim synthetic `
  --policy q4-bisect --seed 101 --n-sources 16 --scenario random
```

冻结参数、配对结果和验证范围见 [`RESULTS.md`](RESULTS.md)。

`learned` 的生产配置不变。该策略仅使用在线观测，不读取源数、场景标签或
模拟器真值。
