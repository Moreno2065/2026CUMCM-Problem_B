# 几何定位＋联合路线优化

入口：`python run.py --mode q3 --seed 101 --n-sources 10 --scenario random`。

默认 Q4 使用 sparse25 严格证书、前 2 个证书点主动复测；Q3 中心点若发现至少 6 个 ACTIVE 频道，兜底无收缩阈值提高到 18，否则为 9，Q4 为 8；证书点按当前位置近邻重排。

每次 ACTIVE 决策同时计算测向收缩、到其他未结频道的后续距离和局部多源聚集收益。它仍使用统一执行器的 READY、有限兜底和严格证书分支，因而只有在所有源清除或所有频道得到有效无源证书后才结束。输出目录默认是本文件夹下的 `runs/`。
